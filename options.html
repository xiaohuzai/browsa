AI Providers

Configure your AI providers. ?Hermes Agent is the built-in agent backend — just fill in Base URL + API key (its own /v1/runs protocol is used automatically).

LLM providers: any endpoint speaking OpenAI Chat Completions, OpenAI Responses, or Anthropic Messages. Give each an Alias so multiple configs stay distinguishable. Use Ping to verify connectivity. Ark-style bases that already include the version (…/api/v3, …/api/plan/v3) work as-is — the version segment is detected and no extra /v1 is added.
