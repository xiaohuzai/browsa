browsa settings

Configure any OpenAI-compatible endpoint as a provider. The active provider is the one the side panel will send to. Use the Ping button to verify connectivity.

Default context mode

How the side panel attaches the current page when you press Send.

Page size limit

Hard cap on extracted text (chars). Readability typically yields 5-30K; this is a safety net for huge pages. Default 1M is fine for any modern LLM.
