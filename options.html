Content limits

Hard cap on extracted text sent to the model (characters). Readability typically yields 5–30K. Default 1M is safe for any modern LLM.

Very long attachments (e.g. a multi-hour video's transcript) get resent in full on every turn. When one exceeds the threshold below, browsa chunks it, summarizes each chunk, and merges the result once — before it ever enters history.

ASR 字幕识别（火山方舟）

B 站无字幕视频 attach 时，下载音频 → 自动转码为 16kHz 单声道 WAV（方舟无法直接处理 B 站 m4s）→ 上传火山方舟录音文件识别（ASR）生成字幕。需要先开通方舟的音频理解模型并获取 标准版 API Key。

必须是 标准版方舟 API Key（方舟控制台 → API Key 管理里创建）。不要用 Agent Plan / Coding Agent 套餐的 key——实测确认编程套餐不含任何音频理解模型，上传报 404、音频输入报 “audio input is not supported”，无法转写。判断方法：标准 key 能在 …/api/v3 上认证（填错会在转写时报鉴权错误）。

必须用标准版端点 …/api/v3（Files API 上传只在此端点上）。如果填了 Agent Plan 的 …/api/plan/v3，保存时会自动规整回 …/api/v3（套餐端点没有文件上传能力）。
