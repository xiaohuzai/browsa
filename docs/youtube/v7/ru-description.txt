browsa — расширение для Chrome / Edge. Читайте, задавайте вопросы и продолжайте работу рядом с веб-страницей, используя свой привычный ИИ.

В видео показаны четыре связанных сценария:
• Статьи, блоги и техническая документация: прикрепите статью о Transformer, задайте вопрос, затем выделите часть ответа и уточните детали. Формулы LaTeX и диаграммы Mermaid / Graphviz отображаются прямо в боковой панели.
• Видео на YouTube / Bilibili: соберите ключевые моменты интервью на временной шкале и нажмите на отметку времени, чтобы проверить исходный фрагмент.
• Переключение Agent: выберите перенос текущего разговора в другой Agent и продолжайте диалог.
• Продолжение работы в Agent: копируйте сообщения, скачивайте изображения, сохраняйте и восстанавливайте разговоры, затем возвращайтесь к той же сессии Agent. В примере используется Codex.

Расширение бесплатное, с открытым исходным кодом (MIT). Подключите свой API модели, Ollama или поддерживаемый Agent. Стоимость работы модели зависит от вашего провайдера.
