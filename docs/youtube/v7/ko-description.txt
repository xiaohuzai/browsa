페이지에 머무르고, 곁에서 물어보세요.
browsa는 Chrome / Edge 확장 프로그램입니다. 평소 사용하는 AI와 웹페이지 옆에서 내용을 읽고, 질문하고, 작업을 이어가세요.

영상은 네 가지 흐름을 보여줍니다.
• 글·블로그·기술 문서 읽기: Transformer 문서를 첨부해 질문하고, 답변의 일부를 선택해 추가로 질문합니다. 수식과 Mermaid / Graphviz 구조도를 사이드 패널에서 바로 확인하세요.
• YouTube / Bilibili 영상 보기: 인터뷰 핵심 내용을 타임라인으로 정리하고, 타임스탬프를 클릭해 원본의 해당 장면을 확인합니다.
• Agent 전환하기: 현재 대화를 가져갈지 선택하고, 다른 Agent와 대화를 이어갑니다.
• Agent에서 작업 계속하기: 메시지 복사, 이미지 다운로드, 대화 저장·복원 후 같은 Agent 세션을 다시 이어갑니다. Codex를 예로 보여줍니다.

확장 프로그램은 무료 오픈 소스(MIT)입니다. 본인의 모델 API, Ollama 또는 지원되는 Agent를 연결해야 합니다. 모델 이용 요금은 서비스 제공자에 따라 달라집니다.
