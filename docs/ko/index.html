데모

페이지에 머무르고, 곁에서 물어보세요.

browsa는 나의 AI나 에이전트를 연결하는 Chrome / Edge 확장 프로그램입니다. Transformer 학습을 기사, 어텐션 수식, Mermaid Q/K/V 흐름, Graphviz 구조, 별도의 AI 업무 장편 인터뷰에서 클릭 가능한 핵심 내용으로 연결합니다. 수식과 컬러 Graphviz는 실제 Codex 답변을 browsa 확장에서 렌더링한 결과입니다. 다른 언어는 설명을 번역하고 같은 수식과 도형을 유지합니다. 브라우저 프레임, 기사와 인터뷰는 데모 구성입니다. Agent 이어하기는 데모로 표시되며 재생은 편집되었습니다. 음악과 동작 효과음만 사용합니다.

작동 방식

세 단계로 웹페이지와 대화하기

창을 옮길 필요도, 복사-붙여넣기도 없습니다. browsa는 지금 읽고 있는 페이지 곁에 조용히 머무르는 페이지 여백의 메모처럼 동작합니다.

01

사이드 패널 열기 Ctrl+Shift+H

아무 페이지에서나 단축키를 누르거나 툴바 아이콘을 클릭하세요. browsa 패널이 오른쪽에 나타납니다.

02

페이지 첨부 📎

📎을 클릭하면 페이지 내용이 대화로 흘러 들어갑니다 — 아티클, 자막, PDF. 선택한 텍스트는 바로 질문할 수도 있습니다.

03

답변 스트리밍 어떤 백엔드든

답변은 단어 단위로 스트리밍되며 Markdown, 수식, 차트를 갖춰 나타납니다. 직접 쓰는 OpenAI 호환 API와 Hermes / opencode / OpenSquilla 에이전트 — 구독으로 로그인한 Codex / Claude Code, agent-bridge로 연결하는 Google 로그인 Gemini CLI, 또는 자체 모델을 구성해 둔 pi를 연결하세요. UI는 브라우저 언어를 따라갑니다 — English, 中文, 日本語, 한국어, Español, Português, Русский — 설정에서 언제든 바꿀 수 있습니다.

설치했나요? 빠른 시작이 첫 질문까지 안내하고, 전체 가이드는 읽기, 동영상, 렌더링, 세션, 백엔드, 설정을 다룹니다.

기능

채팅창 그 이상

browsa는 '읽기'와 '묻기'를 한곳에 모읍니다: 긴 아티클, 동영상, PDF를 읽는 동안 AI가 항상 바로 옆에 있습니다.

attach

페이지 첨부

클릭 한 번으로 현재 페이지를 대화로 가져옵니다 — 모드는 알아서 골라집니다:

  • 자동 계단식: Readability 본문 → DOM 트리 → 전체 텍스트
  • 📷 스크린샷 모드, 멀티모달 모델용
  • PDF 로컬 파싱: WASM이 표 / 제목 / 레이아웃을 재구성하고 그림은 자동으로 잘라 냅니다
  • GitHub 파일 페이지는 페이지 정리를 건너뛰고 raw 소스를 직접 가져옵니다
select

선택 영역 Q&A

아무 페이지에서 텍스트를 선택해 바로 질문하세요:

  • 플로팅 툴바: 질문 · 설명 · 번역 · 요약
  • 설명 / 번역은 그 자리에서 인라인으로 답합니다 — 스트리밍, 그 자리에서, 패널 없이
  • 질문 / 요약: 선택 영역이 패널로 전달됩니다 — 먼저 📎를 누를 필요가 없습니다
render

풍부한 렌더링

답변은 단순 텍스트 그 이상 — 수식과 다이어그램이 브라우저 안에서 렌더링됩니다:

  • Markdown GFM + 40개 이상 언어의 구문 강조
  • LaTeX 수식 (KaTeX, Web Worker 가속)
  • Mermaid 다이어그램, ECharts, Markmap 마인드맵
  • 파싱에 실패한 Mermaid 블록? 구성해 둔 AI에게 고쳐 다시 그리도록 요청하세요
video

동영상 노트

동영상을 위한 완전한 워크플로 — YouTube와 Bilibili의 구조화된 자막:

  • 답변에는 동영상을 해당 시점으로 이동시키는 클릭 가능한 [mm:ss] 타임스탬프가 붙습니다
  • 자막 없는 Bilibili 동영상도 요약할 수 있습니다 — 자동 ASR 전사
  • 긴 전사문은 타임스탬프를 유지한 채 자동으로 요점으로 압축됩니다
provider

어떤 백엔드든

벤더 종속 없음 — 내 모델을 연결하세요:

  • Hermes 에이전트: 도구 실행, 위험 작업 승인, 진행 상태 표시
  • OpenCode 에이전트: opencode CLI 에이전트와 직통 연결 — 동일한 전체 도구 & 승인 흐름
  • OpenSquilla 에이전트: 게이트웨이 WebSocket으로 연결하는 로컬 데스크톱 에이전트 — 서버 측 세션 메모리, 사고 과정 출력, 서버 측 취소
  • Agent Bridge: 로컬 CLI 에이전트를 연결합니다 — 구독으로 로그인한 Codex / Claude Code (모델 쪽은 내 구독으로 동작), Google 로그인 Gemini CLI, 또는 원하는 모델을 구성해 둔 pi; 한 카드로 여러 에이전트를 동시에 연결하며 각자 독립적인 세션과 핑 상태를 갖습니다
  • 에이전트와의 대화는 에이전트 쪽에 남습니다: browsa가 세션 이름을 자동으로 붙이므로('browsa:' + 첫 메시지) 에이전트 자체 인터페이스에서 이어서 작업할 수 있습니다; 세션 ID는 세션 드로어에서 표시되고 복사할 수 있습니다
  • 모든 OpenAI 호환 API: OpenAI, Ollama, LiteLLM…
  • 카드에 모델을 여러 개 추가 — 사이드바에서 '별칭 · 모델'로 전환
  • 모델별 사고 수준: 선택지는 모델 계열을 따르고 요청 필드는 각 API 방언에 맞게 조정됩니다
  • Ping으로 연결 상태와 지원 기능을 확인합니다
privacy

프라이버시 우선

browsa 계정은 없습니다. 모델 서비스는 내 선택:

  • API 키는 로컬에 저장되고 구성한 프로바이더 인증에만 사용됩니다
  • 페이지 컨텍스트의 URL은 전송 전 로컬에서 마스킹됩니다 — 토큰, 비밀번호, 서명은 제거됩니다
  • PDF는 기기 안에서 파싱되며, 추출된 텍스트와 이미지는 모델 요청에 첨부할 수 있습니다
  • Office 문서(docx/pptx/xlsx/…)는 기기 안에서 Markdown으로 변환되며, 추출된 내용은 모델 요청에 첨부할 수 있습니다
  • 내용은 내가 구성한 백엔드로만 전송됩니다
input

빠른 입력

더 두드리지 않고 더 말하기:

  • 빠른 작업: 요약 / 핵심 / 설명 / 목차
  • 슬래시 명령 + ↑/↓ 입력 기록; 작성 중인 문구는 패널을 닫아도 남습니다
  • 답변이 스트리밍되는 동안에도 계속 입력 — 메시지는 대기열에 쌓여 순서대로 전송됩니다
  • 컴포저에 코드를 붙여넣으면 내 버블이 강조된 코드 블록으로 렌더링합니다(복사 버튼, 언어 자동 감지); 나머지 텍스트는 바이트 그대로 유지됩니다
session

세션

긴 대화도 정돈된 상태로:

  • 이름 있는 세션 저장 / 복원, Markdown 내보내기
  • 답변 도중에 세션을 바꿔도 답변은 끊기지 않습니다 — 백그라운드에서 끝까지 진행되어 시작된 세션에 기록됩니다
  • 대화 내 전체 텍스트 검색(Ctrl+F)
  • 답변의 어떤 텍스트든 '상세 스레드'로 파고들어도 메인 기록은 그대로입니다; 이미지를 바로 붙여넣을 수 있고, 입력창의 ↑/↓는 이어서 던진 질문만 불러오며, 인용된 수식은 수식으로 렌더링됩니다

지켜볼 뿐, 가로채지 않습니다: 추출은 브라우저 자체의 요청을 지켜보는 방식으로 동작합니다 — 첨부할 때 필요에 따라 사이트 API도 요청합니다. 첨부된 내용은 설정한 모델이나 Agent로 전송할 수 있습니다. 그 밖의 모든 웹페이지도 동작하며, 다만 이만큼 깊지는 않습니다.

내 키, 내 에이전트

키는 내 것. 모델도 내 것. 에이전트도 내 것.

browsa는 구독을 팔지 않고, 계정을 요구하지 않고, 추가 수수료를 붙이지 않습니다. 단지 내 모델 엔드포인트를 사이드 패널로 옮겨줄 뿐입니다 — 클라우드든, 로컬이든, 자체 호스팅이든.

  • ›계정도, 텔레메트리도 없습니다. 설치하고 바로 사용 — 어떤 데이터도 우리를 거치지 않습니다.
  • ›API 키는 로컬에만 저장되며, 내가 구성한 엔드포인트로만 전송됩니다.
  • ›Ollama / LM Studio 로컬 모델 — 완전한 오프라인도 가능합니다.
  • ›진짜 에이전트: 도구 실행, 실시간 진행 상황, 위험 작업 전 승인.
