browser side-panel AI

读到哪里，问到哪里。

browsa 是一个 Chrome / Edge 侧边栏扩展：不用复制粘贴，点击 📎 就把当前页面带进对话——正文、字幕、PDF 都能读，回答在旁侧流式渲染。

安装 browsa Ctrl+Shift+H 查看源码 ↗
v0.31.9 Chrome / Edge 114+ MIT 开源 800+ 单元测试 10 站点结构化提取

视频笔记：回复自带可点击的 [mm:ss] 时间戳，点击直接跳到视频对应位置。

how it works

三步，开始和网页对话

不换窗口，不复制粘贴。browsa 安静地停在你正在读的页面旁边，像页边批注一样。

01

打开侧边栏 Ctrl+Shift+H

在任意网页按快捷键，或点工具栏图标。browsa 侧边栏随即出现在页面右侧。

02

附带当前页面 📎

点击 📎，页面内容自动进入对话：正文、字幕、PDF 都能读。选中的文字也能直接提问。

03

流式回答 任意后端

回答逐字流式渲染，Markdown、公式、图表一应俱全。连接你自己的 OpenAI 兼容 API 或 Hermes Agent。

features

它不只是一个聊天框

browsa 把「读」和「问」放在同一个界面：读长文、看视频、翻 PDF 时，AI 就在旁边。

attach

页面附带

一键把当前页面带进对话，多个模式自动选择：

  • Auto 智能级联：Readability 正文 → DOM 树 → 全文
  • 📷 截图模式，把可见区域发给多模态模型
  • PDF 本地解析：WASM 重建表格 / 标题 / 版式，图片区域自动裁剪
  • GitHub 文件页直接取 raw 源码，不走页面清理
render

富文本渲染

回答不止是纯文本——全部在本地渲染，不依赖任何服务：

  • Markdown GFM + 40+ 语言代码高亮
  • LaTeX 公式（KaTeX Web Worker 加速）
  • Mermaid 流程图、ECharts 图表、Markmap 思维导图
video

视频笔记

面向视频的完整工作流——YouTube 与 B 站字幕结构化提取：

  • 回复自带可点击的 [mm:ss] 时间戳，点击直达对应画面
  • 无字幕的 B 站视频，可在本地转写（ASR）
  • 自动把长字幕压缩成要点，保留原时间标记
provider

任意后端

不用厂商锁定，连你自己的模型：

  • Hermes Agent：工具执行、危险操作审批、进度展示
  • 任意 OpenAI 兼容 API：OpenAI、Ollama、LiteLLM…
  • Ping 一键检测连通性与模型能力
privacy

隐私优先

无账号、无云端、无数据中转：

  • API Key 只存在本地 chrome.storage
  • PDF 全程本地解析，字节不出设备
  • 内容只发给你自己配置的后端地址
session

会话管理

长对话也能从容整理：

  • 保存 / 恢复命名会话，导出 Markdown
  • 会话内全文搜索（Ctrl+F）
  • 选中回复中的任意文字「细聊」，不污染主对话

supported sites

读得懂你的网页

对以下站点，browsa 直接读取页面已加载的结构化数据——字幕、评论、正文、行情——而不是靠猜。

YouTube字幕/章节 Bilibili字幕/ASR/统计 小红书笔记/评论 掘金文章源码 知乎文章/回答 X / Twitter推文/回复 雪球行情/帖子 小宇宙播客 得到文章 极客时间文章

不劫持、不改动：这些站点通过拦截浏览器自身发起的请求来提取内容，就像在旁边「看」—— 无需重新认证，也不向第三方上传任何东西。

install

安装（开发者模式）

browsa 是未打包扩展，通过开发者模式加载。整个过程约 5 分钟，不收取任何费用。

1

获取代码

git clone 仓库，或从 Releases 下载 zip 并解压。

2

加载扩展

打开 chrome://extensions（Edge 用 edge://extensions）→ 开启「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择 browsa/ 目录。

3

配置并开始

按 Ctrl+Shift+H 打开侧边栏 → ⚙ 设置里填入 Base URL 与 API Key → 点 Ping 验证 → 开聊。

# 1. 获取代码
git clone https://github.com/xiaohuzai/browsa.git

# 2. 安装依赖（可选，仅开发用）
npm install

# 3. 跑测试（800+ 个）
npm test

# 4. 打发布包 → browsa-v<version>.zip
npm run package   # 或直接加载已解压目录
