为什么选 browsa

跟同类侧边栏 AI 对比，browsa 解决的是"数据自主 + 工具能力"这两个痛点。

能力 browsa 普通 SaaS 侧边栏
API 后端自带（Hermes / Claude Code / OpenAI 兼容）厂商锁定
订阅费免费，MIT 开源月付 $10-20
工具执行能跑 bash、读写文件、搜索（Agent Provider）通常不能
站点结构化提取10+ 站点拦截 XHR，拿到字幕、转录、评论仅正文文本
数据流向你的 API Key 直发后端，不经第三方经厂商服务器
Mermaid / ECharts / LaTeX全支持，Web Worker 加速部分支持或无
会话管理本地存储、命名、导出 Markdown、全文搜索云端存储为主

核心功能

不只是一个聊天框--browsa 是一个完整的阅读辅助工作站。

💬

流式对话

Token 逐字显示，Esc 中断。支持 think 块折叠、消息编辑重发、细聊侧线对话。

📎

页面内容附带

Auto 模式用 Mozilla Readability 提取正文，截图模式发可见区域 PNG 给多模态模型。

🎨

富文本渲染

  • Markdown GFM + 40+ 语言代码高亮
  • LaTeX 公式（KaTeX Web Worker 加速）
  • Mermaid 流程图、ECharts 图表
  • Diff 语法高亮
🔍

站点结构化提取

对 10+ 站点拦截 XHR 提取结构化内容，不靠 Readability 猜测——见下表。

🎛️

多 Provider 支持

Hermes Agent（含工具执行）、Claude Code、任意 OpenAI 兼容 API。Ping 按钮一键检测。

⌨️

快捷操作

  • Slash 命令：/summarize /translate 等
  • 选中文字浮窗：Ask / Explain / 翻译 / 摘要
  • 右键菜单：选中文字直接发问
📂

会话管理

命名保存会话、浏览历史、导出 Markdown、会话内全文搜索（Ctrl+F）、多选批量删除。

⚙️

精细配置

  • 域名规则：不同站点不同系统提示
  • Mask 规则：正则脱敏手机号等
  • 回复语言、最大字符数、llms.txt

支持的 Provider

分两类：Agent Provider 能执行工具（bash、文件操作、网络搜索），LLM Provider 只做对话。

🤖 AGENT

Hermes Agent

自托管 AI Agent，内置工具（web 搜索、终端、文件操作、记忆、技能）。用 /v1/runs API，支持工具进度展示和危险操作审批。

🤖 AGENT

Claude Code

通过 claude-code-openai-wrapper 把 Claude Code CLI 暴露为 OpenAI 兼容 API，完整工具能力（bash、文件读写）。

💬 LLM

OpenAI 兼容

任何 /v1/chat/completions 端点：OpenAI、Anthropic、Ollama、Groq、LiteLLM 等。需指定 Model ID。

安装指南

browsa 是未打包扩展，通过开发者模式加载。

1

Clone 或下载仓库

git clone https://github.com/xiaohuzai/browsa.git 或从 Releases 下载 zip

2

打开扩展管理页

Chrome 访问 chrome://extensions，Edge 访问 edge://extensions

3

启用开发者模式

页面右上角打开「Developer mode」开关

4

加载 unpacked

点击「Load unpacked」→ 选择 browsa/ 目录

5

打开侧边栏

按 Ctrl+Shift+H 或点击工具栏图标

6

配置 Provider

点击 ⚙ Settings，选一个 Provider，填 Base URL + API Key，点 Ping 验证

Slash 命令

在输入框打 / 触发补全，所有命令都能追加额外指令。

# 摘要并聚焦方法论
/summarize focus on the methodology

# 翻译但保留技术术语英文
/translate keep technical terms in English

/summarize   3-5 条要点摘要
/translate  翻译成中文
/rewrite    更简洁的重写，保留所有事实
/explain    用简单语言给初学者解释
/outline    仅标题的嵌套大纲
/keypoints  前 5 条关键信息
