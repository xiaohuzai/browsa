browser side-panel AI

读到哪里，问到哪里。

browsa 是一个 Chrome / Edge 侧边栏扩展：不用复制粘贴，点击 📎 就把当前页面带进对话——正文、字幕、PDF 都能读，回答在旁侧流式渲染。

how it works

三步，开始和网页对话

不换窗口，不复制粘贴。browsa 安静地停在你正在读的页面旁边，像页边批注一样。

01

打开侧边栏 Ctrl+Shift+H

在任意网页按快捷键，或点工具栏图标。browsa 侧边栏随即出现在页面右侧。

02

附带当前页面 📎

点击 📎，页面内容自动进入对话：正文、字幕、PDF 都能读。选中的文字也能直接提问。

03

流式回答 任意后端

回答逐字流式渲染，Markdown、公式、图表一应俱全。连接你自己的 API：OpenAI、Anthropic、Ollama、LiteLLM…或 Hermes / opencode 智能体，也可以用 agent-bridge 桥接订阅登录的 Codex / Claude Code。界面文字跟随浏览器语言，也可手动切换中英文。

装好了？快速上手带你完成第一次提问；完整使用指南覆盖读取、视频、渲染、会话、后端与设置。

features

它不只是一个聊天框

browsa 把「读」和「问」放在同一个界面：读长文、看视频、翻 PDF 时，AI 就在旁边。

attach

页面附带

一键把当前页面带进对话，多个模式自动选择：

  • Auto 智能级联：Readability 正文 → DOM 树 → 全文
  • 📷 截图模式，把可见区域发给多模态模型
  • PDF 本地解析：WASM 重建表格 / 标题 / 版式，图片区域自动裁剪
  • GitHub 文件页直接取 raw 源码，不走页面清理
select

划词提问

在任意网页划选一段文字，直接问：

  • 浮动工具栏：提问 · 解释 · → 中文 · 总结
  • 解释 / 翻译就地流式作答，读完即走，不打开侧栏
  • 提问 / 总结：选区自动送进侧边栏，不用先点 📎
render

富文本渲染

回答不止是纯文本——全部在本地渲染，不依赖任何服务：

  • Markdown GFM + 40+ 语言代码高亮
  • LaTeX 公式（KaTeX Web Worker 加速）
  • Mermaid 流程图、ECharts 图表、Markmap 思维导图
  • 图表画不出来？一键让 AI 修复重绘
video

视频笔记

面向视频的完整工作流——YouTube 与 B 站字幕结构化提取：

  • 回复自带可点击的 [mm:ss] 时间戳，点击直达对应画面
  • 字幕抽屉：字幕随播放实时高亮，点击任意行跳转，「记一笔」留住当前这句
  • 无字幕的 B 站视频也能总结——自动 ASR 语音转写，或「视频精读」：画面（幻灯片、屏幕代码）与语音一起理解，消耗更高、默认仍为音频转写
  • 自动把长字幕压缩成要点，保留原时间标记
provider

任意后端

不用厂商锁定，连你自己的模型：

  • Hermes Agent：工具执行、危险操作审批、进度展示
  • OpenCode Agent：opencode CLI 智能体直连，同样是完整的工具与审批流
  • Agent Bridge：桥接订阅登录的 Codex / Claude Code——模型侧订阅登录即可，一张卡可同时连多个 agent
  • 多协议接入：OpenAI（Chat / Responses）、Anthropic Messages、Ollama、LiteLLM…
  • 一张卡可填多个模型（逗号分隔），侧边栏按「别名 · 模型」逐个切换
  • Ping 一键检测连通性与模型能力
privacy

隐私优先

无账号、无云端、无数据中转：

  • API Key 只存在本地 chrome.storage
  • 页面内容发送前本地脱敏——URL 中的令牌、密码、签名参数自动隐去
  • PDF 全程本地解析，字节不出设备
  • 内容只发给你自己配置的后端地址
input

高效输入

不动手打长句也能把话说清楚：

  • 快捷按钮：总结 / 要点 / 解释 / → 中文 / 大纲
  • 斜杠命令 + ↑/↓ 召回历史；草稿关掉面板也不丢
  • 回答没结束也能继续输入，自动排队依次发送
session

会话管理

长对话也能从容整理：

  • 保存 / 恢复命名会话，导出 Markdown
  • 会话可置顶，按标题与内容全文检索
  • 会话内全文搜索（Ctrl+F）
  • 选中回复中的任意文字「细聊」，不污染主对话

supported sites

读得懂你的网页

对以下站点，browsa 直接读取页面已加载的结构化数据——字幕、评论、正文、行情——而不是靠猜。

YouTube字幕/章节 Bilibili字幕/ASR/统计 小红书笔记/评论 飞书文档/表格 掘金文章源码 知乎文章/回答 X / Twitter推文/回复 Reddit帖子/评论 雪球行情/帖子 小宇宙播客 得到文章 极客时间文章

不劫持、不改动：这些站点通过拦截浏览器自身发起的请求来提取内容，就像在旁边「看」—— 无需重新认证，也不向第三方上传任何东西。任意其他网页同样可用，只是没这么「深」。

your keys, your agent

你的钥匙，你的模型，你的智能体。

browsa 不卖订阅、不设账号、不加价。它只是把你自己的模型接口搬进侧边栏——云端的、本地的、自建的，都行。

  • ›无账号、无遥测。安装即用，没有任何数据流经我们。
  • ›API Key 只存本地，只发往你自己配置的端点。
  • ›Ollama / LM Studio 本地模型——完全离线也能用。
  • ›接真智能体：工具执行、过程直播、危险操作先审批。

install

安装

两种方式二选一：商店一键安装，或从 GitHub 加载最新版。整个过程约 5 分钟，不收取任何费用。

1

Chrome 应用商店（最省事）

到 Chrome 应用商店点「添加至 Chrome」。商店版会自动更新，但审核有延迟，可能比 GitHub 版晚几天。

2

或：从 GitHub 加载（最新功能先到这里）

git clone 仓库，或从 Releases 下载 zip 并解压 → 打开 chrome://extensions（Edge 用 edge://extensions）→ 开启「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择 browsa/ 目录。需要较新的 Chrome / Edge——近年自动更新过的浏览器都满足。

3

配置并开始

按 Ctrl+Shift+H 打开侧边栏 → ⚙ 设置里填入 Base URL 与 API Key → 点 Ping 验证 → 开聊。
