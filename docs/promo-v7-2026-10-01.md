文档举例用 Transformer；访谈参考“硅谷101”的采访形式，采用原创“AI 怎样改变工作”演示，没有使用真实节目品牌、人物、声音或片段。五个渲染特性保留在真实 sidepanel 中，通过镜头推近展示，避免独立卡片削弱插件认知。

另有三条获客短片：读技术文档并追问（24秒）、点击访谈观点回到原片（16.6秒）、在 Codex 继续同一个会话（24秒）。完整片负责解释产品，短片各只介绍一个结果。配套 [小规模增长实验](growth-experiments-2026-10-01.md) 记录上手观察、渠道实验与自愿回访。

素材为中文、英文、日文、韩文、西班牙文、巴西葡萄牙文、俄文七语。使用用户选定的 Cat Walk — Arulo，配动作音效，无旁白；每个视频另有去背景音乐但保留音效的版本。主片2049帧/1080p/30fps；GIFdemo-v16采用新文件名，海报poster-v7。

主片公式和彩色 Graphviz 使用实际 Codex 回复，完整侧栏由已加载的真实扩展拍摄；七语翻译说明文字，数学与图结构、颜色保留。Mermaid、分子与蛋白质使用原生前端渲染的冻结示例。浏览器框架与文章是编辑构图，其余工作流通过真实前端与演示传输层拍摄，命令行接续明确标为 DEMO。中文获客文档片使用真实 Codex 回答与追问；中文 Agent 片验证了同一会话 ID 的续接，命令与回答以有标注的重排画面展示。其他六语获客片使用本地化演示数据。片中播放经过剪辑，不代表在线响应速度。
