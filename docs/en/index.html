browser side-panel AI

Read anywhere, ask anywhere.

browsa is a Chrome / Edge side-panel extension: no copy-pasting — click 📎 to bring the current page into the conversation — articles, subtitles, PDFs — and stream replies right next to it.

how it works

Three steps to talk to a webpage

No window-switching, no copy-pasting. browsa sits quietly beside the page you're reading — like a margin note.

01

Open the side panel Ctrl+Shift+H

Press the shortcut or click the toolbar icon on any page. The browsa panel appears on the right.

02

Attach the page 📎

Click 📎 and the page content flows into the conversation — articles, subtitles, PDFs. Selected text can be asked about directly.

03

Stream replies any backend

Replies stream in word by word, with Markdown, math and charts. Connect your own OpenAI-compatible API, the Hermes / opencode agents — or your subscription-logged-in Codex / Claude Code via agent-bridge. The UI follows your browser language — English / 中文 switchable.

Installed? Quick start walks you through the first question; the full guide covers reading, video, rendering, sessions, backends and settings.

features

More than a chat box

browsa puts "reading" and "asking" in the same place: long articles, videos, PDFs — the AI is right there.

attach

Attach the page

Bring the current page into the conversation with one click — modes pick themselves:

  • Auto cascade: Readability body → DOM tree → full text
  • 📷 Screenshot mode, for multimodal models
  • PDF parsed locally: WASM rebuilds tables / headings / layout, figures auto-cropped
  • GitHub file pages pull raw source directly, skipping page cleanup
select

Selection Q&A

Select any text on any page and ask directly:

  • Floating toolbar: Ask · Explain · Translate · Summarize
  • Explain / Translate answer inline — streaming, in place, no panel
  • Ask / Summarize: the selection rides into the panel — no 📎 needed first
render

Rich rendering

Replies are more than plain text — all rendered locally, no external services:

  • Markdown GFM + 40+ language syntax highlighting
  • LaTeX math (KaTeX, Web Worker accelerated)
  • Mermaid diagrams, ECharts, Markmap mind maps
  • A Mermaid block that won't parse? One click asks the AI to fix and re-render it
video

Video notes

A complete workflow for video — structured subtitles from YouTube and Bilibili:

  • Replies carry clickable [mm:ss] timestamps that seek the video
  • Subtitle-less Bilibili videos can still be summarized — automatic ASR transcription
  • Long transcripts auto-compressed into points, timestamps preserved
provider

Any backend

No vendor lock-in — connect your own models:

  • Hermes Agent: tool execution, approval for risky actions, progress display
  • OpenCode Agent: direct line to the opencode CLI agent — same full tool & approval flow
  • Agent Bridge: bridges your subscription-logged-in Codex / Claude Code — the model side runs on your subscription; one card connects several agents at once
  • Any OpenAI-compatible API: OpenAI, Ollama, LiteLLM…
  • Multiple models per card (comma-separated) — switch via “Alias · model” in the sidebar
  • Ping to verify connectivity and capabilities
privacy

Privacy first

No account, no cloud, no data relay:

  • API keys live only in local chrome.storage
  • URLs in page context are masked locally before sending — tokens, passwords and signatures stripped
  • PDFs parsed entirely on-device — bytes never leave
  • Content goes only to the backend you configure
input

Fast input

Say more without typing more:

  • Quick actions: Summarize / Key Points / Explain / Outline
  • Slash commands + ↑/↓ input history; drafts survive closing the panel
  • Keep typing while a reply streams — messages queue and send in order
session

Sessions

Long conversations stay organized:

  • Save / restore named sessions, export Markdown
  • Full-text in-conversation search (Ctrl+F)
  • "Detail-thread" any text in a reply without touching the main history

install

Install

Two ways to pick from: one click from the Chrome Web Store, or load the newest build from GitHub. About 5 minutes, free forever.

1

Chrome Web Store — easiest

Open the Chrome Web Store listing and click Add to Chrome. The store build updates itself, but store review can lag a few days behind the GitHub build.

2

Or: load from GitHub — newest features first

git clone the repo, or download and unzip from Releases → open chrome://extensions (or edge://extensions) → enable Developer mode → Load unpacked → select the browsa/ folder. A recent Chrome / Edge works — any auto-updated browser from the last few years.

3

Configure and go

Press Ctrl+Shift+H to open the panel → in ⚙ Settings add a Base URL and API key → Ping to verify → start chatting.
