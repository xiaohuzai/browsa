Cheat sheet

The complete list of slash commands and keyboard shortcuts.

Slash commands

Type / in the composer for autocomplete. Every command accepts extra instructions: /summarize focus on the methodology:

CommandPrompt sent to the model
/summarize3–5 bullet summary
/translateTranslate to Chinese
/rewriteMore concise rewrite, keeping all facts
/explainExplain for a beginner in simple language
/outlineNested outline of headings only
/keypointsTop 5 takeaways
/promptShow the current active system prompt (not sent to the model)

Quick actions

One-click buttons above the composer: Summarize / Key Points / Explain / Outline — equivalent to the matching slash commands.

When you select text on a page, the floating toolbar offers Ask · Explain · Translate · Summarize — Explain and Translate answer inline (streaming card next to the selection), Ask and Summarize go to the panel; the right-click menu (browsa › …) sends all four to the panel.
