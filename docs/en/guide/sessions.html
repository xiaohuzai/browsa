Guide / Sessions & organizing

Sessions & organizing

History is one growing conversation — don't fear it getting long. Save, search, export, and bulk-organize; the tools live in the drawer and the shortcuts.

Saving & restoring sessions

The 🕐 button in the top bar opens the sessions drawer: save the current conversation under a name and restore it anytime. The list groups by age (Today / Yesterday / This week / Earlier), and favorites can be pinned to the top.

  • Restoring a session brings the whole history back into the panel, ready to continue;
  • Any session can be exported as a Markdown file;
  • Sessions can be renamed.
New topic? Save a session. browsa's conversation is one global thread — "save session + clear" is the smoothest way to organize topics.

Search

  • Ctrl+F: full-text search across the current conversation, matches highlighted with a count and wraparound jumping;
  • The drawer's search box filters saved sessions by title and message content — content-only hits are flagged.

Deleting, with a safety net

  • Messages support multi-select batch deletion;
  • Session deletion is two-step: the first click arms the button, the second commits (Ctrl/Cmd+click skips the arming);
  • Ctrl+K clears the current history and is undoable for 5 seconds.

Input that keeps up

  • ↑/↓ recalls previously sent messages — tweak and resend;
  • Closed the panel mid-sentence? Your draft survives, ready next time;
  • Slash commands, quick actions, selection toolbar — see the cheat sheet.
