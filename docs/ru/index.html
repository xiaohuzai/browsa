демо

Оставайтесь на странице. Спрашивайте рядом.

browsa — расширение для Chrome / Edge с вашим ИИ или агентом. Изучение Transformer связывает статью, формулу внимания, поток Q/K/V в Mermaid, архитектуру в Graphviz и кликабельные тезисы отдельного большого интервью об ИИ и работе. Формулы и цветной Graphviz взяты из настоящего ответа Codex, отображённого расширением browsa. В других версиях переведён текст, формулы и граф сохранены. Рамка браузера, статья и интервью — демонстрационная композиция. Продолжение в Agent отмечено DEMO, воспроизведение смонтировано. Только музыка и звуки действий.

как это работает

Три шага, чтобы поговорить с веб-страницей

Без переключения окон и копирования-вставки. browsa тихо стоит рядом со страницей, которую вы читаете, — как заметка на полях.

01

Откройте боковую панель Ctrl+Shift+H

Нажмите сочетание клавиш или щёлкните значок расширения на любой странице. Панель browsa появится справа.

02

Прикрепите страницу 📎

Щёлкните 📎 — и содержимое страницы вливается в диалог: статьи, субтитры, PDF. Выделенный текст можно спросить напрямую.

03

Ответы — потоком любой бэкенд

Ответы приходят слово за словом, с Markdown, формулами и графиками. Подключите свой OpenAI-совместимый API, агентов Hermes / opencode / OpenSquilla — ваш Codex / Claude Code со входом по подписке, Gemini CLI со входом через Google через agent-bridge, pi с настроенными на нём моделями, а также dsh со входом по аккаунту DeepSeek или API-ключу. Интерфейс следует языку вашего браузера — English, 中文, 日本語, 한국어, Español, Português, Русский — переключается в настройках.

Уже установили? Быстрый старт доведёт вас до первого вопроса; полное руководство расскажет про чтение, видео, рендеринг, сессии, бэкенды и настройки.

возможности

Больше, чем чат-бокс

browsa ставит «чтение» и «вопросы» в одно место: длинные статьи, видео, PDF — ИИ прямо рядом.

attach

Прикрепление страницы

Добавьте текущую страницу в диалог одним щелчком — режимы выбираются сами:

  • Автокаскад: текст через Readability → DOM-дерево → полный текст
  • 📷 Режим скриншота — для мультимодальных моделей
  • PDF разбирается локально: WASM восстанавливает таблицы, заголовки и вёрстку, иллюстрации вырезаются автоматически
  • Страницы файлов на GitHub подтягивают исходный код напрямую, минуя чистку страницы
select

Вопрос-ответ по выделению

Выделите любой текст на любой странице и спросите напрямую:

  • Плавающая панель: Спросить · Объяснить · Перевести · Обобщить
  • Объяснить / Перевести отвечают инлайн — потоком, на месте, без панели
  • Спросить / Обобщить: выделение сразу уезжает в панель — сперва жать 📎 не нужно
render

Богатый рендеринг

Ответы — это не только простой текст: формулы и диаграммы рендерятся в вашем браузере:

  • Markdown GFM + подсветка синтаксиса для 40+ языков
  • Математика LaTeX (KaTeX, ускорение через Web Worker)
  • Диаграммы Mermaid, графики ECharts, майнд-карты Markmap
  • Блок Mermaid не парсится? Попросите свою настроенную нейросеть починить и перерендерить его
video

Заметки по видео

Полный рабочий процесс для видео — структурированные субтитры с YouTube и Bilibili:

  • В ответах — кликабельные метки [mm:ss], которые перематывают видео
  • Видео Bilibili без субтитров тоже можно пересказать — автоматическая ASR-транскрипция
  • Длинные транскрипты автоматически сжимаются до тезисов, таймкоды сохраняются
provider

Любой бэкенд

Никакой привязки к вендору — подключайте свои модели:

  • Hermes Agent: исполнение инструментов, подтверждение рискованных действий, показ прогресса
  • OpenCode Agent: прямой канал к CLI-агенту opencode — тот же полный цикл инструментов и подтверждений
  • OpenSquilla Agent: локальный настольный агент через WebSocket его шлюза — память сессий на сервере, вывод размышлений, отмена на стороне сервера
  • Agent Bridge: мост к локальным CLI-агентам — Codex / Claude Code со входом по подписке (за модель платит ваша подписка), Gemini CLI со входом через Google, pi с любой моделью, которую вы ему настроите, а также dsh со входом по аккаунту DeepSeek или API-ключу; одна карточка подключает несколько агентов сразу, у каждого своя сессия и свой статус ping
  • Диалоги с агентами живут на стороне агента: browsa сама называет сессию («browsa:» + ваше первое сообщение), так что вы подхватите её в собственном интерфейсе агента; ID сессии показывается и копируется в панели сессий
  • Любой OpenAI-совместимый API: OpenAI, Ollama, LiteLLM…
  • Несколько моделей на карточке — переключение через «Псевдоним · модель» в боковой панели
  • Уровень размышлений для каждой модели: варианты следуют за семейством модели, а поля запроса подстраиваются под каждый API-диалект
  • Ping проверяет связь и возможности
privacy

Приватность прежде всего

Без аккаунта browsa. Сервис моделей выбираете вы:

  • API-ключи хранятся локально и используются для аутентификации у настроенного вами провайдера
  • URL в контексте страницы маскируются локально перед отправкой — токены, пароли и подписи вырезаются
  • PDF разбирается на устройстве; извлечённые текст и изображения можно приложить к запросам к модели
  • Офисные документы (docx/pptx/xlsx/…) преобразуются в Markdown на устройстве; извлечённый контент можно приложить к запросам к модели
  • Контент уходит только на тот бэкенд, который настроили вы
input

Быстрый ввод

Скажите больше, не печатая больше:

  • Быстрые действия: Обобщить / Тезисы / Объяснить / Структура
  • Слэш-команды + история ввода ↑/↓; черновики переживают закрытие панели
  • Печатайте, пока ответ ещё генерируется, — сообщения встанут в очередь и уйдут по порядку
  • Вставьте код в поле ввода — ваш собственный пузырь отрисует его подсвеченным блоком (кнопка копирования, язык определяется автоматически); всё остальное остаётся байт-в-байт
session

Сессии

Длинные диалоги остаются в порядке:

  • Сохранение и восстановление именованных сессий, экспорт в Markdown
  • Переключение сессии посреди ответа не убивает ответ — он завершится в фоне и попадёт в ту сессию, где начался
  • Полнотекстовый поиск по диалогу (Ctrl+F)
  • «Уточняющий вопрос» к любому тексту ответа — без затрагивания основной истории; изображения вставляются прямо в карточку; ↑/↓ в поле ввода карточки поднимает только уточняющие вопросы; процитированные формулы рендерятся как математика

ваши ключи, ваш агент

Ваши ключи. Ваши модели. Ваш агент.

browsa не продаёт подписку, не требует аккаунт, не берёт наценку. Он просто переносит ваши собственные эндпоинты моделей в боковую панель — облако, локальные или самохостинг.

  • ›Без аккаунта и без телеметрии. Установили — и всё: через нас не проходит ничего.
  • ›API-ключи остаются локальными и уходят только на настроенные вами эндпоинты.
  • ›Локальные модели Ollama / LM Studio — полностью офлайн тоже подходит.
  • ›Настоящие агенты: исполнение инструментов, живой прогресс, подтверждение перед рискованными действиями.
