demo

Quédate en la página. Pregunta a su lado.

browsa es una extensión para Chrome / Edge que conecta tu IA o agente. Un estudio de Transformers enlaza artículo, fórmula de atención, flujo Q/K/V con Mermaid, arquitectura con Graphviz y puntos pulsables de una entrevista independiente y extensa sobre IA en el trabajo. Las fórmulas y Graphviz en color proceden de una respuesta real de Codex renderizada en browsa. Las demás ediciones traducen el texto y conservan las fórmulas y el diagrama. El marco del navegador, artículo y entrevista son demos compuestas. La continuación en Agent está marcada como DEMO y la reproducción está editada. Solo música y sonidos de acciones.

cómo funciona

Tres pasos para hablar con una página web

Sin cambiar de ventana, sin copiar y pegar. browsa permanece en silencio junto a la página que estás leyendo — como una nota al margen.

01

Abre el panel lateral Ctrl+Shift+H

Pulsa el atajo o haz clic en el icono de la barra de herramientas en cualquier página. El panel de browsa aparece a la derecha.

02

Adjunta la página 📎

Haz clic en 📎 y el contenido de la página fluye a la conversación — artículos, subtítulos, PDF. El texto seleccionado se puede preguntar directamente.

03

Respuestas en streaming cualquier backend

Las respuestas llegan en streaming palabra a palabra, con Markdown, matemáticas y gráficos. Conecta tu propia API compatible con OpenAI, los agentes Hermes / opencode / OpenSquilla — tu Codex / Claude Code con la sesión de tu suscripción, el Gemini CLI con login de Google vía agent-bridge, o pi con sus propios modelos configurados. La interfaz sigue el idioma de tu navegador — English, 中文, 日本語, 한국어, Español, Português, Русский — y se puede cambiar en Ajustes.

¿Ya lo tienes instalado? La guía rápida te acompaña hasta tu primera pregunta; la guía completa cubre lectura, vídeo, renderizado, sesiones, backends y ajustes.

funciones

Más que un cuadro de chat

browsa pone «leer» y «preguntar» en el mismo sitio: artículos largos, vídeos, PDF — la IA está justo ahí.

attach

Adjuntar la página

Lleva la página actual a la conversación con un clic — los modos se eligen solos:

  • Cascada automática: cuerpo Readability → árbol DOM → texto completo
  • 📷 Modo captura de pantalla, para modelos multimodales
  • PDF analizado localmente: el WASM reconstruye tablas / encabezados / diseño, figuras recortadas automáticamente
  • Las páginas de archivos de GitHub obtienen el código fuente directamente, saltándose la limpieza de la página
select

Preguntas sobre la selección

Selecciona cualquier texto en cualquier página y pregunta directamente:

  • Barra flotante: Preguntar · Explicar · Traducir · Resumir
  • Explicar / Traducir responden en línea — en streaming, en el propio sitio, sin panel
  • Preguntar / Resumir: la selección viaja al panel — sin necesidad de 📎 antes
render

Renderizado enriquecido

Las respuestas son más que texto plano — fórmulas y diagramas se renderizan en tu navegador:

  • Markdown GFM + resaltado de sintaxis para más de 40 lenguajes
  • Matemáticas LaTeX (KaTeX, acelerado con Web Worker)
  • Diagramas Mermaid, ECharts, mapas mentales Markmap
  • ¿Un bloque Mermaid que no se puede analizar? Pide a tu IA configurada que lo corrija y lo vuelva a renderizar
video

Notas de vídeo

Un flujo de trabajo completo para el vídeo — subtítulos estructurados de YouTube y Bilibili:

  • Las respuestas llevan marcas de tiempo [mm:ss] clicables que saltan al momento del vídeo
  • Los vídeos de Bilibili sin subtítulos también se pueden resumir — transcripción ASR automática
  • Las transcripciones largas se comprimen automáticamente en puntos, conservando las marcas de tiempo
provider

Cualquier backend

Sin dependencia de ningún proveedor — conecta tus propios modelos:

  • Agente Hermes: ejecución de herramientas, aprobación de acciones de riesgo, progreso visible
  • Agente OpenCode: línea directa con el agente CLI de opencode — el mismo flujo completo de herramientas y aprobaciones
  • Agente OpenSquilla: agente de escritorio local vía su gateway WebSocket — memoria de sesión en el servidor, salida del razonamiento, cancelación en el servidor
  • Agent Bridge: conecta agentes CLI locales — Codex / Claude Code con la sesión de tu suscripción (el lado del modelo funciona con tu suscripción), el Gemini CLI con login de Google, o pi con el modelo que le configures; una sola tarjeta conecta varios agentes a la vez, cada uno con su propia sesión y estado de Ping
  • Las conversaciones con agentes viven en el lado del agente: browsa nombra la sesión automáticamente («browsa:» + tu primer mensaje) para que puedas retomarla en la propia interfaz del agente; el ID de sesión se muestra y se puede copiar en el historial de sesiones
  • Cualquier API compatible con OpenAI: OpenAI, Ollama, LiteLLM…
  • Añade varios modelos por tarjeta — cambia mediante «Alias · modelo» en la barra lateral
  • Nivel de razonamiento por modelo: las opciones siguen a la familia del modelo y los campos de la petición se adaptan a cada dialecto de API
  • Ping para verificar la conectividad y las capacidades
privacy

Privacidad primero

Sin cuenta de browsa. El servicio de modelos lo eliges tú:

  • Las claves de API se guardan localmente y solo se usan para autenticarte con tu proveedor configurado
  • Las URL del contexto de la página se enmascaran localmente antes de enviarlas — tokens, contraseñas y firmas eliminados
  • Los PDF se analizan en el dispositivo; el texto y las imágenes extraídas se pueden adjuntar a las peticiones del modelo
  • Los documentos de Office (docx/pptx/xlsx/…) se convierten a Markdown en el dispositivo; el contenido extraído se puede adjuntar a las peticiones del modelo
  • El contenido va únicamente al backend que tú configuras
input

Entrada rápida

Di más sin escribir más:

  • Acciones rápidas: Resumir / Puntos clave / Explicar / Esquema
  • Comandos de barra diagonal + historial de entrada ↑/↓; los borradores sobreviven al cerrar el panel
  • Sigue escribiendo mientras llega la respuesta — los mensajes se ponen en cola y se envían en orden
  • Pega código en el compositor — tu propia burbuja lo renderiza como un bloque resaltado (botón de copiar, lenguaje detectado automáticamente); todo lo demás se conserva byte a byte
session

Sesiones

Las conversaciones largas se mantienen ordenadas:

  • Guarda / restaura sesiones con nombre, exporta como Markdown
  • Cambiar de sesión a mitad de respuesta nunca la interrumpe — termina en segundo plano y queda en la sesión donde empezó
  • Búsqueda de texto completo en la conversación (Ctrl+F)
  • «Preguntar más» sobre cualquier texto de una respuesta sin tocar el historial principal; pega imágenes directamente; el ↑/↓ del cuadro de entrada recupera solo las preguntas de seguimiento; las fórmulas citadas se muestran como matemáticas

tus claves, tu agente

Tus claves. Tus modelos. Tu agente.

browsa no vende suscripciones, no pide cuenta, no cobra recargos. Simplemente lleva tus propios endpoints de modelos al panel lateral — en la nube, local o autoalojado.

  • ›Sin cuenta ni telemetría. Instala y usa — nada pasa nunca por nosotros.
  • ›Las claves de API se quedan en local, enviadas solo a los endpoints que configures.
  • ›Modelos locales con Ollama / LM Studio — también funciona totalmente sin conexión.
  • ›Agentes de verdad: ejecución de herramientas, progreso en vivo, aprobación antes de las acciones de riesgo.
