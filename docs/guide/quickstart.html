指南 / 快速上手

快速上手

四步：装好扩展 → 打开侧边栏 → 连接你自己的模型 → 发出第一个问题。全程约五分钟。

1 · 安装扩展

1

获取代码

git clone 仓库，或从 Releases 下载 zip 并解压。

2

加载扩展

打开 chrome://extensions（Edge 用 edge://extensions）→ 开启「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择 browsa/ 目录。需要 Chrome / Edge 114 及以上——近年自动更新过的浏览器都满足。

browsa 是未打包扩展，通过开发者模式加载，不收取任何费用，也不会申请安装时弹窗之外的任何东西。

2 · 打开侧边栏

在任意网页按 Ctrl+Shift+H（macOS 为 Command+Shift+H），或点击工具栏里的 browsa 图标。侧边栏随即出现在页面右侧，你切到哪个标签页，它就跟到哪个标签页。

3 · 连接你自己的模型

browsa 不内置任何模型——它把你自己配置的后端搬进侧边栏。点击侧边栏右上角的 ⚙ 设置：

  • 普通对话模型：任何兼容 OpenAI、Anthropic 或 Ollama 的端点。填 Base URL + API Key + 模型 ID，点 Save 保存。
  • Hermes Agent：自带工具执行的自托管智能体（可选，安装方法见连接后端）。

保存后点 Ping 验证连通性——第一个 Ping 通的提供商会自动设为当前使用。

没有 API Key？本机装一个 Ollama（localhost:11434）就能完全离线使用；各云服务商的控制台也都提供 Key。字段含义与多模型配置见连接后端一页。

4 · 发出第一个问题

  1. 打开一篇你想读的文章（或视频、PDF），按 Ctrl+Shift+H 打开侧边栏。
  2. 点击输入框旁的 📎——当前页面被附加进对话，输入框上方会显示一条「已附加」的说明。
  3. 输入问题，Enter 发送。回答逐字流式渲染，Markdown、公式、图表都直接画在面板里。

不想打字也可以用输入框上方的快捷按钮：总结 / 要点 / 解释 / → 中文 / 大纲，一键对当前页面执行对应任务。

browsa 的使用习惯是「先附加，后提问」。页面内容附加一次就一直在上下文里，之后每一轮提问都带着它——所以先点 📎，再慢慢想问什么，完全来得及。

界面语言

设置里可以把界面文字切换为 English / 中文 / Auto（跟随浏览器语言），即时生效，无需重载。回答用什么语言，可以在设置里用「回复语言」固定下来。
