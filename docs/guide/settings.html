设置与隐私

设置不多，每一条都解决一个具体问题。这一页同时把「数据流向哪里」讲透。

设置一览

设置作用
系统提示词每轮对话以 role: system 注入——回复语言、语气、格式规则都在这里定
回复语言不管页面是什么语言，固定用指定语言回答
界面语言English / 中文 / Auto（跟随浏览器），即时生效
划词工具栏与 llms.txt开关划选文字时的浮动工具栏；附加页面时携带站点自带的 llms.txt 说明
阅读偏好消息字号、发送快捷键（Enter / Ctrl+Enter）、自动滚动开关
ASR 字幕识别无字幕视频的语音转写服务商（默认火山方舟）：API Key、语言、字幕来源

另有两件事自动发生、无需配置：发送前，页面上下文里所有 URL 的凭据（令牌、密码、签名参数）在本机被抹掉；超过约 100,000 字符的长附件在后台分块总结、合并，[mm:ss] 时间标记保留。

数据流向哪里

browsa 的隐私边界只有一句话：你的数据只在你自己的浏览器和你自己配置的后端之间流动。具体到机制：

  • API Key 只存本机（chrome.storage.local），除了你填的 Base URL 之外不发往任何地方；
  • 没有账号、没有遥测——安装即用，没有任何数据流经开发者；
  • PDF 全程本机解析（WASM + pdf.js），文件字节不出设备，只有提取出的文本发给你配置的模型；
  • 发送前本地脱敏：页面内容里所有 URL 的凭据（token、密码、签名、会话 ID）在本机就被抹掉；
  • 内容脚本只观察网络请求，从不修改、拦截或重放它们；
  • 模型回复先过 DOMPurify 消毒再渲染，Mermaid 的 SVG 另行剥离脚本与事件属性。

完整版见隐私政策。

浏览器兼容

Chrome / Edge 114 及以上（主要目标）；Brave 1.56+ 理论可用（同一 Chromium 内核）。Firefox 不支持——没有侧边栏 API。
