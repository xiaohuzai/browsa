# browsa 界面优化 · 2026-10-01

完成上一轮审查中的六类可复现问题和四项界面调整。保留现有墨色、纸白、橙色体系，让当前模型、页面阅读和发送操作保持清晰。产品界面先定稿，后续七语宣传片与演示 GIF 已按该界面完成。

## 已实施

- 顶栏：当前模型/Agent 在首行、服务商在次行；原生选择框仍提供完整名称和连通状态。设置与会话管理常驻顶栏，视频时间线在有视频时显示；搜索、多选收进带完整文字的「⋯ 更多操作」。Escape、点击外部、离开焦点和选择操作会关闭面板，键盘退出恢复入口焦点；系统强制配色使用原生文字。
- 快捷栏：完整标签自动换行，七语所有操作都在可见区域，保留折叠偏好。
- 输入区：清空消息使用垃圾桶图标（按后续用户反馈恢复），保留原清空确认流程；占位符使用在实际输入表面可读的语义色。
- 会话：置顶、重命名、导出、删除共享按钮样式，最低 24×24 CSS px；新增直接重命名，列表刷新不会收走刚打开的另一会话编辑框，保留双击/F2、Enter 保存、Escape 取消和输入法保护。导出采用同款 SVG。
- 设置：窄页语言标签独占一行，选择框可收缩，保存始终可见；服务商组说明换行，窄屏标签栏获得整行空间；删除/密钥显示按钮扩大，密钥显示与连接检查统一 SVG。
- 七语：HTML lang 和相对/绝对日期跟随界面语言；auto 按浏览器语言匹配已提供的词典，不支持的语言回落英文；葡语使用 pt-BR。打开的会话抽屉在语言切换时刷新。五种非中文语言的设置页帮助入口统一指向英文深度指南。主聊天时间戳也采用相同语言规则。
