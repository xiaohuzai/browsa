privacy policy

隐私政策

生效日期：2026-10-01 · 适用范围：browsa 浏览器扩展及官网

无 browsa 账号、无遥测、无开发者中转服务器。扩展在本地保存设置和对话；你使用 AI 功能时，相关内容由浏览器直接发送到你配置的模型或 Agent 服务。

处理哪些数据

browsa 为提供阅读和对话功能处理以下数据，不向开发者发送使用记录、页面内容或个人信息。没有分析埋点，也不出售用户数据。公开源代码可在 github.com/xiaohuzai/browsa（MIT 协议）审计。

  • 网页与文件：当前页面的地址、标题、正文、字幕，以及你附加的文档、截图或图片。支持站点的内容脚本会在页面加载时观察已加载的数据，以便后续提取；附加内容用于对话上下文。
  • 对话与设置：你的问题、模型回复、附件、会话存档、模型与 Agent 配置，以及界面偏好。
  • 认证信息：你填写的 API Key 用于向对应服务认证；按需获取平台媒体时会使用该平台的登录态。
  • 音视频（可选）：你选择转写或分析的媒体内容，用于生成字幕、笔记或视听分析结果。

数据存在哪里

  • 对话历史（包括已保存的附件图片）、会话存档、服务配置、API Key 和偏好保存在本机的 chrome.storage.local；临时运行状态使用内存或 chrome.storage.session。browsa 不提供云同步。
  • 可在扩展内删除消息、会话或修改配置；卸载扩展会移除其浏览器存储。你另外导出的文件需要自行删除。
  • 发送到模型、Agent 或分析服务的数据，其处理与留存由该服务的设置和隐私政策决定；删除本地会话不会删除服务端副本。

网络请求发往哪里

  • 模型和 Agent：对话、问题及相关附件内容直接发送到你在设置中配置的地址，不经过 browsa 开发者的服务器。API Key 随对应服务的认证请求发送。连接检查也会请求所配置的服务。发起的回合可在切换会话后继续运行。
  • 本地解析与模型请求：PDF、Office 文档在本机解析为文字和图片；这些提取结果可以附加并发送给配置的模型或 Agent。页面上下文中的 URL 会在发送前隐去可识别的令牌、密码、签名等凭据；这不是对正文敏感信息的全面过滤，也不会改写实际下载资源所用的地址。
  • 站点内容提取：除读取已加载的数据外，browsa 会按需向当前站点及其接口请求正文、评论、字幕、文档或媒体，例如原始代码文件与 arXiv 论文元数据。请求可能带有浏览器已有的登录态；arXiv 元数据查询发送论文编号，不发送对话。
  • 音视频分析（可选）：浏览器按需从平台或 CDN 拉取媒体，必要时使用该平台的 Cookie、Referer 等请求头；本地转码后向你配置的转写或分析服务发送音频/分析输入。只有启用并使用相关功能才进行这些处理。
  • 回复中的外部资源：渲染回复图片会访问图片来源；按编号显示蛋白质结构会访问结构数据库（如 RCSB 或 AlphaFold）并发送相应结构编号。这些请求不发送完整对话。
  • 官网：网页字体来自 Google Fonts，浏览器会直接向其请求字体资源；官网不添加分析或追踪脚本。打开外部链接后适用目标网站的隐私政策。

权限用途说明

  • <all_urls> / tabs / scripting：读取和附加页面、截图或文档，按需注入提取脚本，连接你配置的服务，以及点击时间戳时跳转视频进度。支持站点的观察脚本和划词工具会随页面加载；不会把整个浏览历史上传给开发者。
  • cookies：视听分析按需获取平台媒体时读取该平台的登录态，以构造所需请求头，不发送给开发者。
  • declarativeNetRequest：媒体拉取期间使用临时会话级规则补充 Referer 等请求头，用后移除，浏览器会话结束自动清除。
  • webNavigation：侧边栏开启期间感知页面导航，更新当前页面信息。
  • storage / unlimitedStorage：保存上述本地设置、对话及附件。
  • sidePanel / contextMenus：显示聊天侧栏和右键快捷操作。
  • alarms：清理临时流状态等后台运行维护，不用于遥测。

第三方服务

browsa 开发者不运营用于接收扩展数据的后台。你选择的模型、Agent、分析服务，以及内容来源站点，分别适用各自的隐私条款。使用本机模型时，模型请求可以留在设备上；本地 Agent 是否调用外部模型或工具取决于它自身的配置。

未成年人

browsa 不要求提供年龄，也不针对未成年人收集数据。使用配置的第三方服务时适用该服务的年龄要求与隐私政策。

变更与联系

政策如有实质性变更，会在本页更新并修改生效日期。有任何疑问请提 Issue：github.com/xiaohuzai/browsa/issues。
