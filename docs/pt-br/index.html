demo

Fique na página. Pergunte ao lado dela.

O browsa é uma extensão para Chrome / Edge que conecta sua IA ou agente. Um estudo de Transformers liga artigo, fórmula de atenção, fluxo Q/K/V com Mermaid, arquitetura com Graphviz e pontos clicáveis de uma entrevista longa e independente sobre IA no trabalho. As fórmulas e o Graphviz colorido vêm de uma resposta real do Codex renderizada no browsa. As outras versões traduzem o texto e mantêm as fórmulas e o diagrama. A moldura do navegador, artigo e entrevista são composições de demonstração. A continuação no Agent é marcada como DEMO e a reprodução é editada. Apenas música e sons de ações.

como funciona

Três passos para conversar com uma página web

Sem alternar janelas, sem copiar e colar. O browsa fica quieto ao lado da página que você está lendo — como uma nota à margem.

01

Abra o painel lateral Ctrl+Shift+H

Pressione o atalho ou clique no ícone da barra de ferramentas em qualquer página. O painel do browsa aparece à direita.

02

Anexe a página 📎

Clique em 📎 e o conteúdo da página flui para a conversa — artigos, legendas, PDFs. O texto selecionado pode ser perguntado diretamente.

03

Receba respostas em streaming qualquer backend

As respostas chegam palavra por palavra, com Markdown, matemática e gráficos. Conecte a sua própria API compatível com OpenAI, os agentes Hermes / opencode / OpenSquilla — o seu Codex / Claude Code com login de assinatura, o Gemini CLI com login Google via agent-bridge, ou o pi com os modelos que você configurar nele. A interface segue o idioma do seu navegador — English, 中文, 日本語, 한국어, Español, Português, Русский — alternável nas Configurações.

Já instalou? O início rápido conduz você até a primeira pergunta; o guia completo cobre leitura, vídeo, renderização, sessões, backends e configurações.

recursos

Mais do que uma caixa de chat

O browsa coloca "ler" e "perguntar" no mesmo lugar: artigos longos, vídeos, PDFs — a IA está bem ali.

attach

Anexe a página

Traga a página atual para a conversa com um clique — os modos se escolhem sozinhos:

  • Cascata automática: corpo via Readability → árvore DOM → texto completo
  • 📷 Modo captura de tela, para modelos multimodais
  • PDF processado localmente: o WASM reconstrói tabelas / títulos / layout, figuras recortadas automaticamente
  • Páginas de arquivo do GitHub puxam o código-fonte direto, pulando a limpeza da página
select

Perguntas sobre a seleção

Selecione qualquer texto em qualquer página e pergunte diretamente:

  • Barra flutuante: Perguntar · Explicar · Traduzir · Resumir
  • Explicar / Traduzir respondem inline — em streaming, no lugar, sem painel
  • Perguntar / Resumir: a seleção entra no painel — sem precisar do 📎 antes
render

Renderização rica

As respostas vão além do texto puro — fórmulas e diagramas renderizam no seu navegador:

  • Markdown GFM + realce de sintaxe para mais de 40 linguagens
  • Matemática LaTeX (KaTeX, acelerado por Web Worker)
  • Diagramas Mermaid, ECharts, mapas mentais Markmap
  • Um bloco Mermaid que não renderiza? Peça à sua IA configurada para corrigi-lo e renderizá-lo novamente
video

Notas de vídeo

Um fluxo de trabalho completo para vídeo — legendas estruturadas do YouTube e do Bilibili:

  • As respostas trazem [mm:ss] clicáveis que saltam o vídeo para o momento
  • Vídeos do Bilibili sem legendas também podem ser resumidos — transcrição ASR automática
  • Transcrições longas são comprimidas automaticamente em pontos, com os timestamps preservados
provider

Qualquer backend

Sem lock-in de fornecedor — conecte os seus próprios modelos:

  • Agente Hermes: execução de ferramentas, aprovação de ações arriscadas, exibição de progresso
  • Agente OpenCode: linha direta com o agente CLI opencode — o mesmo fluxo completo de ferramentas e aprovações
  • Agente OpenSquilla: agente desktop local via WebSocket do gateway — memória de sessão no servidor, saída do raciocínio, cancelamento pelo servidor
  • Agent Bridge: conecta agentes CLI locais — Codex / Claude Code com login de assinatura (o lado do modelo roda na sua assinatura), o Gemini CLI com login Google, ou o pi com o modelo que você configurar nele; um único cartão conecta vários agentes ao mesmo tempo, cada um com sua própria sessão e status de ping
  • As conversas com agentes ficam no lado do agente: o browsa nomeia a sessão automaticamente ("browsa:" + a sua primeira mensagem) para você retomá-la na interface do próprio agente; o ID da sessão é exibido e pode ser copiado na gaveta de sessões
  • Qualquer API compatível com OpenAI: OpenAI, Ollama, LiteLLM…
  • Adicione vários modelos por cartão — alterne via “Apelido · modelo” na barra lateral
  • Nível de raciocínio por modelo: as opções seguem a família do modelo e os campos da requisição se adaptam a cada dialeto de API
  • Ping para verificar conectividade e capacidades
privacy

Privacidade em primeiro lugar

Sem conta no browsa. Serviço de modelo à sua escolha:

  • As chaves de API ficam armazenadas localmente e são usadas para autenticar no provedor que você configurou
  • URLs no contexto da página são mascaradas localmente antes do envio — tokens, senhas e assinaturas removidos
  • PDFs são processados no dispositivo; o texto e as imagens extraídos podem ser anexados às requisições do modelo
  • Documentos Office (docx/pptx/xlsx/…) são convertidos para Markdown no dispositivo; o conteúdo extraído pode ser anexado às requisições do modelo
  • O conteúdo vai somente para o backend que você configurar
input

Entrada rápida

Diga mais sem digitar mais:

  • Ações rápidas: Resumir / Pontos principais / Explicar / Estrutura
  • Comandos de barra + histórico de entrada com ↑/↓; os rascunhos sobrevivem ao fechamento do painel
  • Continue digitando enquanto a resposta chega — as mensagens entram em fila e são enviadas em ordem
  • Cole código no composer — a sua própria bolha o renderiza como um bloco destacado (botão de copiar, linguagem detectada automaticamente); todo o resto permanece byte a byte
session

Sessões

Conversas longas continuam organizadas:

  • Salve / restaure sessões nomeadas, exporte Markdown
  • Trocar de sessão no meio da resposta nunca interrompe a resposta — ela termina em segundo plano e chega à sessão em que começou
  • Busca de texto completo na conversa (Ctrl+F)
  • Abra um "fio de detalhes" sobre qualquer texto de uma resposta sem tocar no histórico principal; cole imagens direto no campo; o ↑/↓ do campo recorda apenas as perguntas de acompanhamento; as fórmulas citadas renderizam como matemática

suas chaves, seu agente

Suas chaves. Seus modelos. Seu agente.

O browsa não vende assinatura, não exige conta, não cobra taxa extra. Ele apenas leva os seus próprios endpoints de modelo para o painel lateral — nuvem, local ou auto-hospedado.

  • ›Sem conta, sem telemetria. Instale e use — nada jamais passa por nós.
  • ›Chaves de API ficam locais, enviadas apenas aos endpoints que você configurar.
  • ›Modelos locais Ollama / LM Studio — totalmente offline também funciona.
  • ›Agentes de verdade: execução de ferramentas, progresso ao vivo, aprovação antes de ações arriscadas.
