# ADR-0012: 效率审计遗留的刻意不修清单

- 状态：Accepted（2026-09-23 效率审计取舍；**勿当缺陷重报，用户未拍板前勿动**）
- 来源：AGENTS.md 效率审计段 + 全库效率审计复盘

## Context

2026-09-23 全库效率审计修掉了一批热点后，以下条目被**刻意保留现状**——不是漏掉，
是取舍后的决定。未来的缺陷搜寻/效率评审不要把它们当新发现重报。

## Decision（不修清单）

1. **renderHistory 首开同步全量渲染 + 全量 hljs**、近视口进入时的升级二次解析——保留现状。
2. **隐藏元素标记 pass 的 O(n·depth) 成本与布局抖动**——它是提示注入防御的一部分，慎动。
3. **transcript 抽屉 500ms 轮询**（开抽屉期间每秒 2 次 executeScript 注入）——改动属设计变更，
   要动先拍板。
4. **DONE 重发全量回复 + keepalive 双保险**——有意为之，不省。

（savedSessions 逐字快照含图片字节也是同批取舍，见 ADR-0005。）

## Consequences

- 重开任一条需要用户拍板；评审报告遇到这四条时标注「ADR-0012 已记」即可。
