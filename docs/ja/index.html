browsa / ブラウザサイドパネル AI

ページはそのまま。質問はそのそばで。

長い記事？難解な論文？テンポの速い動画？ページごと自分の AI との会話に取り込みましょう。コピペも、読んでいるページから離れることもなく、解説が得られます。

デモ

ページから離れず、その隣で尋ねる。

browsa は自分の AI を接続する Chrome / Edge 拡張機能。Transformer の記事を読み、数式と図で理解し、対談の要点をクリックして確認。回答や画像を保存し、同じセッションを Agent で続けます。数式とカラー Graphviz は実際の Codex の回答を browsa 拡張で表示したものです。他言語版は説明文を翻訳し、数式と図を保持します。ブラウザー枠、記事、対談はデモ構成です。Agent の続行はデモと明記し、再生は編集されています。音楽と操作音のみ。

使い方

3 ステップで Web ページと会話

ウィンドウの切り替えも、コピペも不要。browsa は読んでいるページのそばに静かに寄り添います — 余白の注釈のように。

01

サイドパネルを開く Ctrl+Shift+H

ショートカットを押すか、どのページでもツールバーアイコンをクリック。browsa のパネルが右側に現れます。

02

ページを添付 📎

📎 をクリックすると、ページの内容がそのまま会話に流れ込みます — 記事も字幕も PDF も。選択したテキストにはそのまま質問できます。

03

返信をストリーミング表示 どのバックエンドでも

返信は単語ごとにストリーミング表示され、Markdown・数式・チャートに対応します。OpenAI 互換 API、Hermes / opencode / OpenSquilla エージェント — サブスクリプションでログイン済みの Codex / Claude Code、Google ログインの Gemini CLI（agent-bridge 経由）、自分でモデルを設定した pi を接続できます。UI はブラウザの言語に追従 — English・中文・日本語・한국어・Español・Português・Русский — 設定で切り替えられます。

インストール済みですか？クイックスタートで最初の質問まで案内します。完全ガイドでは、読み取り・動画・レンダリング・セッション・バックエンド・設定を解説しています。

機能

ただのチャットボックスではありません

browsa は「読む」と「聞く」を同じ場所に置きます：長い記事も、動画も、PDF も — AI はすぐそばにいます。

attach

ページを添付

クリック 1 つで現在のページを会話に取り込みます — モードは自動で選択：

  • 自動カスケード：Readability 本文 → DOM ツリー → 全文
  • 📷 スクリーンショットモード（マルチモーダルモデル向け）
  • PDF はローカルで解析：WASM が表・見出し・レイアウトを再構築し、図は自動切り抜き
  • GitHub のファイルページは生ソースを直接取得し、ページのクリーンアップをスキップ
select

選択して質問

どのページでもテキストを選択して、そのまま質問：

  • フローティングツールバー：質問 · 解説 · 翻訳 · 要約
  • 解説 / 翻訳はインラインで回答 — ストリーミング、その場で、パネル不要
  • 質問 / 要約：選択範囲がパネルに持ち込まれます — 先に 📎 は不要
render

リッチなレンダリング

返信はただのテキストではありません — 数式も図もブラウザ内で描画：

  • Markdown GFM + 40 以上の言語のシンタックスハイライト
  • LaTeX 数式（KaTeX、Web Worker で高速化）
  • Mermaid 図、ECharts、Markmap マインドマップ
  • パースできない Mermaid ブロック？設定した AI に修正と再描画を依頼できます
video

動画ノート

動画のための完全なワークフロー — YouTube とビリビリから構造化された字幕を取得：

  • 返信にはクリックできる [mm:ss] タイムスタンプが付き、動画をシーク
  • 字幕のないビリビリ動画も要約できます — 自動 ASR 文字起こし
  • 長い字幕は自動で要点に圧縮。タイムスタンプは保持されます
provider

どのバックエンドでも

ベンダーロックインなし — 自分のモデルを接続：

  • Hermes エージェント：ツール実行、危険な操作の承認、進捗表示
  • OpenCode エージェント：opencode CLI エージェントへの直通 — 同じツール実行と承認フロー
  • OpenSquilla エージェント：ゲートウェイ WebSocket 経由でローカルデスクトップエージェントと接続 — サーバー側セッションメモリ、思考出力、サーバー側キャンセル
  • Agent Bridge：ローカル CLI エージェントをブリッジ接続 — サブスクリプションでログイン済みの Codex / Claude Code（モデル側はあなたのサブスクリプションで動作）、Google ログインの Gemini CLI、任意のモデルを設定した pi。1 枚のカードで複数エージェントを同時接続し、それぞれが独自のセッションと Ping 状態を持ちます
  • エージェントとの会話はエージェント側に残ります：browsa がセッション名を自動で付け（「browsa:」+ 最初のメッセージ）、エージェント側のインターフェースで続きを行えます。セッション ID はセッションドロワーで表示・コピーできます
  • OpenAI 互換 API なら何でも：OpenAI、Ollama、LiteLLM…
  • カードに複数のモデルを追加 — サイドバーの「別名 · モデル」で切り替え
  • モデルごとの思考レベル：選択肢はモデルファミリーに追従し、リクエスト項目は各 API の方言に適応
  • Ping で接続と対応機能を確認
privacy

プライバシー第一

browsa のアカウントは不要。モデルサービスは自分で選択：

  • API キーはローカルに保存され、設定したプロバイダの認証にだけ使われます
  • ページコンテキスト内の URL は送信前にローカルでマスク — トークン・パスワード・署名を除去
  • PDF はデバイス上で解析。取り出したテキストと画像はモデルへのリクエストに添付できます
  • Office 文書（docx/pptx/xlsx など）も同様にデバイス上で Markdown に変換 — ファイルがマシンの外に出ることはありません
  • 内容が送られるのは、自分で設定したバックエンドだけ
input

素早い入力

打ち込まずに、より多くを伝えます：

  • クイック操作：要約 / 要点 / 解説 / アウトライン
  • スラッシュコマンド + ↑/↓ の入力履歴。パネルを閉じても下書きは残ります
  • 返信のストリーミング中も入力を続けられます — メッセージは順番にキューイングされ、送信されます
  • 入力欄にコードを貼り付けると、あなたのバブルがハイライト付きブロックとして描画（コピーボタン、言語を自動判定）。それ以外の部分はバイト単位でそのまま
session

セッション

長い会話も整理されたまま：

  • 名前を付けたセッションの保存 / 復元、Markdown エクスポート
  • 返信の途中でセッションを切り替えても返信は止まりません — バックグラウンドで完了し、開始したセッションに記録されます
  • 会話内全文検索（Ctrl+F）
  • 返信内のテキストを選んで、メインの履歴に触れずにスレッドで細かく質問。画像も直接貼り付け可能。入力の ↑/↓ で呼び出されるのは追質問だけ。引用した数式は数式として描画されます

対応サイト

あなたの Web ページを読み取ります

これらのサイトでは、browsa は推測の代わりに、ページがすでに読み込んでいる構造化データ — 字幕・コメント・記事ソース・行情報 — を読み取ります。

観測するだけで、乗っ取りはしません：抽出はブラウザ自身のリクエストを監視する仕組みで動作します — 再認証は不要で、サードパーティーに何かをアップロードすることもありません。それ以外の Web ページもすべて動作します（対応サイトほど深くはありません）。

あなたのキー、あなたのエージェント

キーはあなたのもの。モデルも。エージェントも。

browsa はサブスクリプションを売らず、アカウントも求めず、上乗せ料金も取りません。あなた自身のモデルエンドポイントをサイドパネルに取り込むだけ — クラウドでも、ローカルでも、セルフホストでも。

  • ›アカウント不要、テレメトリもなし。インストールしたらすぐ使える — データがこちらを経由することは一切ありません。
  • ›API キーはローカルに保存され、設定したエンドポイントにだけ送信されます。
  • ›Ollama / LM Studio のローカルモデル — 完全オフラインでも動作します。
  • ›本物のエージェント：ツール実行、リアルタイム進捗、危険な操作の前の承認。
