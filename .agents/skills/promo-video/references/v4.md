仅在用户明确要求回溯 v4 时使用。本页参数不是 v7 参数；现役流程见 [production-v7.md](production-v7.md)。不自动发布、提交或推送。

## 历史 v4 流程

文件都在本 skill 目录。scripts/copy-v4.json 是七语文案与演示数据；scripts/stage-v4.html 是合成舞台；scripts/driver4.mjs 跑真附页、发送、选中追问、视频时间线、审批；scripts/render4.py 编码视频/GIF/海报。生产扩展不导入这些文件。

在仓库根运行：

```bash
npm ci --prefix .agents/skills/promo-video/scripts --no-audit --no-fund
node dev-preview/gen.mjs
node .agents/skills/promo-video/scripts/server.mjs
```

服务器独立保持运行。另一终端：

```bash
node .agents/skills/promo-video/scripts/check-v4-harness.mjs
node .agents/skills/promo-video/scripts/driver4.mjs zh en ja ko es pt-BR ru
python3 .agents/skills/promo-video/scripts/render4.py zh en ja ko es pt-BR ru
python3 .agents/skills/promo-video/scripts/verify4.py
```

Mac 已验证系统 Chrome headless。其他主机先设 PROMO_CHROME 为实际浏览器可执行路径；不要复制 Linux 缓存绝对路径。PROMO_V4_OUT 可改采帧目录，但 render4.py 当前读取 store-assets/promo/v4，变更目录时需同步。v4 未依赖 Remotion 或 WebGL；需要这两者时看 [历史管线](v3.md)，并验证当前主机支持。

仅复查交互可用 `PROMO_VERIFY_ONLY=1 node .agents/skills/promo-video/scripts/driver4.mjs zh en ja ko es pt-BR ru`；保留已采帧，写独立 interaction-verification.json。此检查不代替成片视觉验收。

## 必须验证的结果

- manifest.json 每幕帧数、语言、错误、交互检查。字体加载成功，字典没有静默回退。
- 附页/发送产生真实 UI；选择打开追问卡；SUBCHAT 完整答案可读。检查容器内部 scrollHeight/clientHeight 以及外部舞台裁切，点击中心无遮挡；DOM 中存在文字不等于画面可见。
- 时间线真点击产生 SEEK_VIDEO，目标秒数与可见播放器时间一致。不能只改光标或回成功信封。
- 审批按钮触发 APPROVAL_RESPOND、审批卡消失，再显示演示完成结果。文案说明保存能力来自接入的 Agent。
- 全片播放与动作前后、转场边界、末帧、GIF 循环检查。1080p、官网 960px、GIF 720px 分别看字与裁切；ffprobe 核对时长、帧率、编码。v4 规格为 48s 1080p H.264、18s 720px GIF，采集 12fps、视频编码 24fps。

## 输出与同步

本地源帧/规格：store-assets/promo/v4/（gitignored）。分发视频/海报：docs/assets/promo/browsa-promo-v4-{lang}.mp4 与 poster-v4-{lang}.jpg；GIF：docs/assets/readme/demo-v10-{lang}.gif。文件名 pt-br 小写，脚本参数 pt-BR。新版本编号实施时核对。

七份 README 与七个官网页面各引用对应语言；同步 alt、演示内容和旧 YouTube 标识，不能声称旧链接已是新片。Guide 截图、banner、GIF、视频逐一判断并记录；说明截图跟随产品 UI，宣传片构图变动本身不要求重拍操作截图。发布按当前用户授权与仓库规则，技能不自动授权上传、推送、合并或发布。

常见坑：CDP captureScreenshot 避免某些 dark-mode 截图伪影；iframe 元素需按实际缩放转换光标坐标；涟漪末帧归零；配置资源 URL 必须指向 /repo/ 根，否则七语字典静默回退；不要依赖陈旧 DOM selector 或固定抽屉宽度；失效就停止该镜头并修正，再重拍。
