# CWS 填写包模板

生成时替换所有模板提示；最终文档不能残留占位符。实际字段名称优先用用户的 Dashboard 标签；未看到账号页面时使用字段地图中的官方名称并说明依据。每个复制块只放可粘贴内容。

动作：`更新 / 新增 / 沿用 / 已完成 / 不适用 / 待确认`。沿用不要求重复粘贴；包内元数据只供核对。章节按用户后台顺序排列，下面是没有账号页面时的参考顺序。

````markdown
# browsa vX.Y.Z · CWS 填写包 · YYYY-MM-DD

> 本轮：线上 vBASE → 已上传/准备上传 vX.Y.Z。
> 字段依据：当前账号页面已核对 / 按官方字段文档整理，未核对当前账号界面。
> 本次需操作：逐页列实际字段与理由。
> 待确认：仅列影响本次填写或提交的未知事实；没有则写“无”。

## 1. 软件包

动作：已完成 / 更新；需要更新时操作为上传本轮 ZIP。
列本轮 ZIP 的准确路径或已验证 release 下载链接、版本、最低浏览器版本、权限增减。
已上传包不要求再次上传。不要把分支 manifest 当作已上传包的证明。

| pt_BR | 实际解析值 | 实际解析值 | 同上 |
| ru | 实际解析值 | 实际解析值 | 同上 |

```

```

```

### 分类 / Category、语言 / Language

按后台实际下拉选项列名称、动作、选择值。语言下拉只是切换本地化编辑对象时明确写为操作，不捏造第二个语言配置字段。

### 图片与视频

| 位置 / 字段 | locale | 动作 | 操作：文件绝对路径或 YouTube URL | 尺寸 / 来源与核实状态 |
|---|---|---|---|---|
| 商店图标 / Store icon | 默认 | 沿用或更新 | 实际值 | 128×128 |
| 截图 / Screenshots | 默认 | 沿用或更新（逐张） | 实际文件 | 实际支持尺寸，1–5 张 |
| 宣传视频 / Promo video | 默认 | 沿用或更新 | 单个 YouTube 视频链接 | 可访问、高清处理完成 |
| 小宣传图块 / Small promo tile | 全局 | 沿用或更新 | 实际文件 | 440×280 |
| Marquee promo tile | 全局 | 沿用、不适用或更新 | 实际文件或留空 | 1400×560，可选 |
| Localized screenshots | 各语逐组 | 沿用或更新 | 后台已有覆盖 / 确认无覆盖则沿用默认 / 实际文件 | 实际尺寸与状态 |
| Localized promo video | 各语逐项 | 沿用或更新 | 后台已有覆盖 / 确认无覆盖则沿用默认 / 实际 YouTube URL | 实际状态 |

默认和各语覆盖资源分开列。没有新资源的条目不编造路径；本地缺文件不代表后台无覆盖，未知时保留后台现值并标待确认。

### 其他字段 / Additional fields

分别列首页 URL / Homepage URL、支持 URL / Support URL、官方 URL / Official URL、成人内容 / Mature content。
每个 URL 单独给复制块；官方 URL 写下拉选择值及验证状态；内容分级写实际勾选值。隐私政策 URL 在隐私权章节。
未知且未要求变更的现值保留不动；需要修改的必填项待确认。可选官方 URL 无已验证网站时可留空，已有选择则保留。

## 3. 隐私权 / Privacy practices

### 单一用途说明 / Single purpose description

动作与字符数。

```text
完整单一用途说明
```

### 权限理由 / Permissions justification

**根据实际上传包和后台框逐项展开，不固定框数**。
每项标题写权限名，标动作，每框一个完整复制块。
主机权限理由也单独列；不要把多个理由合为一个不可落位的大段。

### 远程代码 / Remote code

列后台实际选项和应选值；需要理由框时单独给完整文字。

### 数据用途 / Data usage

| 后台的数据类型选项原名 | 勾选 / 不勾选 / 待确认 | 实际处理与去向（核对说明，不粘贴） |
|---|---|---|
| 按实际后台选项逐行展开 | 依据事实 | 本地 / 用户配置端点 / 其他实际去向 |

| 后台的用途认证原文 | 勾选 / 不勾选（不满足） / 待确认 | 依据（核对说明，不粘贴） |
|---|---|---|
| 按后台多项认证逐行展开 | 确实满足才勾选 | 与功能、数据流一致；不满足则说明需修正用途，不标可提交 |

不把“没有开发者遥测”简化成所有数据类型不勾选。

### 隐私政策 URL / Privacy policy URL

```text
经核实的隐私政策 URL
```

## 4. 测试说明 / Test instructions（后台可能译为“访问权限”）

测试说明为可选、非公开字段。动作与实际字符数；本项目保守控制 ≤500，当前控件上限优先。

```text
审核员实际能走通的完整测试说明：无需凭据的界面/提取检查，以及需要配置端点的回答测试；不虚构测试账号或承诺无 Key 能运行 AI
```

后台若出现账号名/密码框，逐项注明是否需要。没有专用测试账号就明确留空，不填个人凭据。

## 5. 分发 / Distribution

| 后台字段 | 动作 | 实际选择值 | 来源与核实状态 |
|---|---|---|---|
| Visibility | 沿用或用户授权更新 | 实际值 | 后台已核实 / 未核实则保留现值不改动 |
| Regions | 沿用或用户授权更新 | 实际值 | 同上 |
| 付费 / 免费（仅实际出现时） | 沿用 | 实际值 | 同上 |

## 6. 操作顺序

1. 核对本轮上传包；已上传则跳过上传步骤。
2. 商品详情依次处理 EN、简中、日、韩、西、葡（巴西）、俄：仅对更新/新增项，在当前语言粘贴完整说明、处理该语覆盖截图/视频，按实际后台方式保存并确认保留后，再切换下一语；沿用项无需重新粘贴。
3. 核对分类、默认素材和全局图块、链接和内容分级；无变化项保留，不假定已有语言覆盖会自动清空回退。
4. 隐私权逐框填单一用途、实际权限理由、远程代码、数据用途和认证、隐私政策 URL。
5. 填或核对测试说明，核对分发；无变化项沿用。
6. 保存，核对后台缺项和警告；处理待确认项后，由用户提交审核。

## 附：内部核对（不填写到 CWS）

用户可见变更表（PR/commit → 行为变化）、权限/数据流判断依据、七语与长度校验、素材是否重拍的逐项判断、未验证信息。
更新清单默认留在此处；如用户要求对外展示，已融入各语完整详细说明，不另设 What's new 字段或填写步骤。
````
